轉換公司債 (CB)

轉換公司債 (Convertible Bond, CB) 是一種特殊的公司債，除了具備一般公司債的固定利息收入外，還賦予投資人將債券轉換成發行公司普通股的權利。這意味著投資人可以在股價上漲時，將債券轉換成股票賺取資本利得；若股價下跌，則仍可持有債券收取利息，相對具有下檔保護。對公司而言，發行 CB 可降低融資成本，並在未來股價上漲時稀釋股權。
