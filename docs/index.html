新手 什麼是「雪球法」？
雪球法是一種投資策略，核心概念是「小額試水、滾動獲利」。當你發現一個有潛力的新題材或個股時，只投入一小筆資金（例如 5,000 元）試水溫，並設定好停損停利目標。如果部位獲利達到預期（例如翻倍或賺到 1-2 萬元），就將一部分獲利（例如 50%）轉入你長期看好的核心資產（如 0050 或 2330），進行「存款操作」，剩下的資金則繼續尋找下一個機會，讓資金像滾雪球一樣不斷壯大。
