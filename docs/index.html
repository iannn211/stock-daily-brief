雪球法

雪球法是一種投資策略，核心概念是利用小倉位資金（例如 NT$5,000）試水新興題材或有潛力的中小型股。當這些小倉位獲利達到一定目標（例如 +30%）時，將部分獲利（例如 50%）轉入穩健資產（如 0050 或 2330）作為「存款」，剩下的資金則繼續在市場中尋找下一個雪球機會。這種方法旨在透過複利效應，讓資金像滾雪球一樣越滾越大，同時透過分散小倉位和及時獲利了結來控制風險。
