去槓桿 (Deleveraging)

去槓桿是指投資人或企業減少債務的行為。在股市中，當市場出現大幅下跌時，使用融資（借錢買股票）的投資人會被要求補繳保證金，若無法補繳就會被強制賣出股票，這種行為會進一步加劇市場跌勢，形成惡性循環。今日 (6/26) 台股重挫，部分原因就是市場在進行去槓桿，使得融資餘額雖然微幅增加，但整體賣壓沉重。
