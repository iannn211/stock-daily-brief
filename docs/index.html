利多出盡

「利多出盡」是指一項好消息（利多）公布後，股價反而下跌的現象。這通常是因為市場預期已將利多反應在股價中，當消息真正公布時，買盤缺乏進一步的動能，甚至出現獲利了結賣壓，導致股價回落。例如，台積電法說會前股價已大漲，若法說會內容不如市場預期，就可能出現利多出盡。
